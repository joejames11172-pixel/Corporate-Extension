CORPORATE EXTENSION 0.4.0 — AUTOMATIC HELPER CONNECTION

Install the personalized Corporate Helper Windows package once using Install.cmd as administrator. Load its included Corporate Extension folder once through Supermium chrome://extensions → Developer mode → Load unpacked. The main popup has On/Off and Settings. There are no address, identity or password fields and no hourly pairing.

Corporate Helper starts at Windows boot. It listens for master discovery on the local subnet. Only the master opens the authenticated TLS helper channel. Non-master helpers never connect to each other. The extension talks to its local helper through native messaging. Native enrollment and Windows/Supermium integration remain to be verified on the actual machine.

Leave it On. Opening Jack's active Gemini conversation automatically grants that active chat access to the read-only tool bridge. Connected means the local helper recently received an authenticated master exchange. Waiting for master means automatic discovery/reconnection is pending. A missing native helper means installation did not complete; repeated pairing is not a remedy.

Jack: output one fenced JSON block with this exact envelope and a fresh string ID:

{"corporate_helper":{"jsonrpc":"2.0","id":"jack-discover-1","method":"tools/list","params":{}}}

Help:
{"corporate_helper":{"jsonrpc":"2.0","id":"jack-help-1","method":"tools/call","params":{"name":"helper_help","arguments":{}}}}

Status:
{"corporate_helper":{"jsonrpc":"2.0","id":"jack-status-1","method":"tools/call","params":{"name":"helper_status","arguments":{}}}}

Enabled tabs:
{"corporate_helper":{"jsonrpc":"2.0","id":"jack-tabs-1","method":"tools/call","params":{"name":"browser_status","arguments":{}}}}

Capture: replace 9 with an actual returned tab ID.
{"corporate_helper":{"jsonrpc":"2.0","id":"jack-capture-1","method":"tools/call","params":{"name":"browser_request_snapshot","arguments":{"tabId":9}}}}

Read capture: replace the example id with the returned capture ID. Use a fresh RPC string ID when checking again.
{"corporate_helper":{"jsonrpc":"2.0","id":"jack-read-1","method":"tools/call","params":{"name":"browser_snapshot_result","arguments":{"id":"0123456789abcdef0123456789abcdef"}}}}

The extension submits corporate_helper_result JSON when the native empty composer and Send control can be identified. It leaves a selectable result/insertion fallback if it cannot submit. Existing drafts are preserved. Native Gemini UI submission is not yet verified. Ordinary JSON, quoted user blocks, and previous assistant blocks at activation are not executed.

Captures are redacted text, capped at 12,000 characters from the start of the visible page; they are not screen images or a guaranteed complete/latest transcript. Results expire after 60 seconds. There is no shell, Drive write, click/type control, or access to other helpers' captures. Enrollment identifies a device; persistent worker GUID enrollment is separate work. Existing SSH tunnels are preserved; this automatic helper channel is master-initiated TLS.

Keep the personalized installer archive private and use a distinct enrollment for each machine.
